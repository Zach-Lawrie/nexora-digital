# Flourish Creations Events

One-page site for Flourish Creations Events (Nissi & Abi), event, wedding and cultural ceremony styling across Sydney and the Southern Highlands.

- `public/index.html`: the whole site (no build step). Fonts: Fraunces, Jost, Pinyon Script.
- `public/img/`: photos from the business's own Instagram (@flourishcreations.events). Three had Instagram's play icon removed.
- Reels play through Instagram's official embed, so new videos are added by putting the post code in the `REELS` list.
- The enquiry form copies the client's details and opens an Instagram DM, because the business takes bookings by DM.
- Hosted on Cloudflare Pages project `flourish-creations` (root `flourish`, output `public`).
