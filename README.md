# Nexora Digital website

Static one-page site for Nexora Digital (websites for Zimbabwe businesses).

- `index.html` – the whole site (HTML, CSS, JS in one file)
- `favicon.svg` – the hexagon "N" mark

## Deploy on Cloudflare Pages
Connect this repo in Cloudflare → Workers & Pages → Create → Pages → Connect to Git.
Framework preset: **None**. Build command: *(leave empty)*. Output directory: `/`.
Every push to `main` redeploys automatically.
